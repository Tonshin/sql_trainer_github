# SQL-тренажёр

Интерактивный тренажёр по SQL на Python и Streamlit. Задачи решаются в браузере, ответ проверяется автоматически: результат вашего запроса сравнивается с результатом эталонного.

- 29 задач в 7 темах: SELECT, WHERE, сортировка, агрегаты и GROUP BY, JOIN, подзапросы, оконные функции
- теория по каждой теме с примерами, которые можно запустить прямо на странице
- учебная база «Компания» (SQLite): отделы, сотрудники, клиенты, товары, заказы
- три уровня подсказок: идея → структура запроса → заготовка с пропусками, которую можно вставить в редактор
- отметки ✅ (решено без подсказок) и ☑️ (решено с подсказками)
- просмотр схемы и данных таблиц; эталонное решение после двух неудачных попыток или всех подсказок
- песочница для произвольных запросов

## Запуск локально

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер по адресу http://localhost:8501.

## Структура

```
app.py            интерфейс Streamlit
engine.py         выполнение запросов и проверка ответов
db/schema.sql     учебная база: таблицы и данные
tasks.yaml        темы и задачи
theory/           теория по темам (Markdown)
tests/            тесты движка, задач и примеров из теории
```

## Как редактировать теорию

Теория лежит в `theory/*.md`, файл привязан к теме полем `theory:` в `tasks.yaml`. Это обычный Markdown, с одним соглашением:

- блок ` ```sql ` показывается с кнопкой «▶ Выполнить пример» и запускается на учебной базе;
- блок ` ``` ` без указания языка — просто текст, например шаблон синтаксиса.

Тесты проверяют, что каждый пример выполняется и возвращает данные.

## Как устроена проверка

- Каждый запрос выполняется на свежей копии базы в памяти, поэтому испортить данные нельзя.
- Разрешены только запросы на чтение (`SELECT`, `WITH ... SELECT`). База открыта в режиме `query_only`, команда `ATTACH` запрещена.
- Время выполнения ограничено 2 секундами, результат — 5000 строками.
- Сравниваются количество и порядок столбцов и значения. Имена столбцов не важны. Дробные числа округляются до 2 знаков.
- Порядок строк учитывается, только если у задачи стоит `ordered: true`.

## Как добавить задачу

Добавьте запись в нужную тему в `tasks.yaml`:

```yaml
- id: my_new_task            # уникальный, не меняйте после публикации
  title: "Короткое название"
  text: "Условие задачи (Markdown)."
  solution: |
    SELECT ...;
  hints:                     # подсказки по нарастающей
    - "Идея: какая конструкция нужна."
    - "Структура: из каких частей собрать запрос."
  template: |                # последний уровень — заготовка с пропусками ___
    SELECT ___ FROM ...;
  ordered: false             # true, если важен порядок строк
```

Подсказок в `hints` может быть сколько угодно, они открываются по очереди, заготовка — последней. Старый формат с одной строкой `hint:` тоже поддерживается.

Затем запустите тесты: они проверят, что эталон выполняется и возвращает данные, что у задачи есть подсказки и заготовка с `___`, и что в задачах на порядок результат однозначен.

```bash
pip install pytest
pytest
```

## Деплой

Streamlit Community Cloud (бесплатный хостинг Streamlit) **работает только с GitHub**, а этот репозиторий лежит на GitLab. Варианты:

1. **Зеркало на GitHub.** Создайте пустой репозиторий на GitHub и настройте в GitLab push-зеркалирование: *Settings → Repository → Mirroring repositories*. После этого на share.streamlit.io выберите GitHub-репозиторий и файл `app.py`.
2. **Другой хостинг**, который умеет работать с GitLab или Docker, например Render или собственный сервер.

Прогресс пользователей хранится только в сессии браузера: после перезагрузки страницы он сбрасывается.
