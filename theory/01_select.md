SQL-запрос на чтение данных начинается с `SELECT`. Самая короткая форма:

```
SELECT <что выбрать> FROM <из какой таблицы>;
```

Ключевые слова можно писать в любом регистре: `select` и `SELECT` работают одинаково. Точка с запятой в конце завершает запрос.

### Все столбцы или только нужные

Звёздочка `*` означает «все столбцы таблицы»:

```sql
SELECT * FROM products;
```

Если нужны только некоторые столбцы, перечислите их через запятую. Столбцы в результате идут в том порядке, в котором вы их написали:

```sql
SELECT name, city FROM customers;
```

> В реальных проектах `*` используют осторожно: при изменении таблицы запрос начнёт возвращать другой набор столбцов.

### Выражения и псевдонимы

В `SELECT` можно не только перечислять столбцы, но и вычислять новые значения: складывать, умножать, склеивать строки (оператор `||`). Чтобы дать столбцу понятное имя, используйте `AS`:

```sql
SELECT name,
       price,
       price * 0.9 AS sale_price
FROM products;
```

```sql
SELECT first_name || ' ' || last_name AS full_name, position
FROM employees;
```

### Убираем повторы: DISTINCT

`DISTINCT` сразу после `SELECT` оставляет только уникальные строки результата:

```sql
SELECT DISTINCT category FROM products;
```

Если указать несколько столбцов, уникальной должна быть их комбинация: `SELECT DISTINCT city, name ...` уберёт только полностью одинаковые строки.

### Шпаргалка

| Конструкция | Что делает |
|---|---|
| `SELECT *` | все столбцы |
| `SELECT a, b` | только столбцы `a` и `b` |
| `expr AS name` | вычисляемый столбец с именем |
| `SELECT DISTINCT` | без повторяющихся строк |
