`WHERE` оставляет в результате только строки, для которых условие истинно. Он пишется после `FROM`:

```
SELECT ... FROM <таблица> WHERE <условие>;
```

### Операторы сравнения

`=`, `<>` (или `!=`), `<`, `>`, `<=`, `>=`. Строки и даты записываются в одинарных кавычках:

```sql
SELECT name, price FROM products WHERE category = 'Мониторы';
```

Даты в формате `YYYY-MM-DD` можно сравнивать как обычные строки: `'2023-05-01' < '2024-01-15'`.

### Несколько условий: AND, OR, NOT

- `AND` — должны выполняться оба условия;
- `OR` — хотя бы одно;
- `NOT` — отрицание.

`AND` выполняется раньше `OR`, поэтому при их смешивании ставьте скобки:

```sql
SELECT name, city, registered_at
FROM customers
WHERE (city = 'Москва' OR city = 'Казань')
  AND registered_at >= '2023-06-01';
```

Без скобок условие прочиталось бы как «Москва ИЛИ (Казань И после июня)».

### IN и BETWEEN

`IN` проверяет вхождение в список. Это короче нескольких `OR`:

```sql
SELECT name, category FROM products
WHERE category IN ('Ноутбуки', 'Мониторы');
```

`BETWEEN a AND b` проверяет диапазон **включая** обе границы: `price BETWEEN 1000 AND 5000` то же самое, что `price >= 1000 AND price <= 5000`.

### Поиск по шаблону: LIKE

- `%` — любое количество любых символов (в том числе ноль);
- `_` — ровно один любой символ.

```sql
SELECT first_name, last_name FROM employees
WHERE last_name LIKE '%ова';
```

### Особый случай: NULL

`NULL` означает «значение неизвестно». Любое сравнение с ним через `=` или `<>` даёт не «истину» и не «ложь», а `NULL`, и строка в результат не попадает. Поэтому для проверки есть отдельные операторы `IS NULL` и `IS NOT NULL`:

```sql
SELECT first_name, last_name, position
FROM employees
WHERE manager_id IS NULL;
```

> Частая ошибка: `WHERE manager_id = NULL` никогда не вернёт ни одной строки.
